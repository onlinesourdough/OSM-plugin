# OSM interface

The agent's workspace is the main working surface. Setup is conversational.
OSM uses the host's built-in tools and side panel before external apps.

The Codex sidebar entry presents the public Notion method guide. It is separate
from the owner's private Data & Context home. The former private dashboard,
pickers, settings drawer and record reader are retired. Native behavior must
be verified before delivery is claimed.

The icon uses the pixel bread from the onlinesourdough website, without a
surrounding circle or background. The adjacent label remains OSM. The sidebar
receives theme-specific glyphs; the package carries a transparent square PNG.
Its [vector source](assets/branding/osm-icon.svg) remains editable.

Earlier dashboard designs and Paper references remain in the
[v0.33.0 design history](https://github.com/onlinesourdough/OSM-plugin/blob/v0.33.0/design.md).
The retired dashboard's Paper export left the active tree after 0.33.0; its
unchanged files remain in the [v0.33.0 Paper folder](https://github.com/onlinesourdough/OSM-plugin/tree/v0.33.0/Paper/3438e04fc0d64ffe).
None of this specifies the current interface.

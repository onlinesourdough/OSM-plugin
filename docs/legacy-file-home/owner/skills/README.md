# Optional owner methods

Keep shared user-owned skills here, each at <name>/SKILL.md. No methods are
bundled in this owner-data starter. Register each canonical body once in each
chosen harness; never duplicate it inside the OSM plugin. External Global
Skills and System/Project methods retain their own owners.

For continuity, identify each transferable personal method with its canonical
source and owner. An unrecorded folder or a shared plugin/library is not a
personal skill merely because it is under `skills/`.

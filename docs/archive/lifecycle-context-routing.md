## Outcome and ownership

An ordinary task selects the result this conversation should deliver and its
continuation before costly production. The shared AIOS lifecycle owns that
decision; Spec makes it usable, Select Model chooses capability/model/reasoning
for the accepted work, and Orchestrate Workers coordinates only delegated work
whose caller retains acceptance. User-ready handoff belongs to the shared
lifecycle, including a link, copyable prompt, attachments and pending obligations.
Respect explicit production requests and preserve sufficient existing context.

Onboarding equips a fresh harness with a small, source-led owner context. It
covers relevant orientation, outcomes, constraints, working preferences and
source/capability routes through verified sources, minimal unique local facts,
or explicit gaps. It reuses accepted answers; no exhaustive interview or fixed
file per topic. Maintain Context owns source choice, freshness, migration and
deduplication. Current external facts stay canonical externally. Owner corrections
retain provenance and narrow scope; ambiguous source conflicts remain visible.

# Launcher provenance

The portable launcher and its retained contract tests derive from
[Agentic Content System](https://github.com/onlinesourdough/Agentic-Content-System)
commit `efeccee065a0444eb701a42398f8ada52bf52450`, paths
`workspace/engine/scripts/diffusion-studio.mjs` and
`workspace/engine/tests/diffusion-studio.test.mjs`.
No tracked LICENSE or NOTICE was present in that ACS source commit; no new
license grant is inferred here. The accepted integration moves only the small
launcher and instructions. External editor code, application licenses, notices,
dependencies, caches and generated builds stay with their own installations.
See [operation](operation.md) for preserved fork, upstream and exact pin identities.

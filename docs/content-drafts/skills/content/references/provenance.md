# Source and license provenance

The content method, graph validator/templates, neutral fixtures, format library,
reference preparation and local transcription helpers were adapted from
[Agentic Content System](https://github.com/onlinesourdough/Agentic-Content-System)
commit `efeccee065a0444eb701a42398f8ada52bf52450` under the accepted AIOS integration.
The source tree at that commit contains no tracked LICENSE or NOTICE file;
this migration invents no upstream license grant. Preserve that fact when
reviewing distribution rights. No customer production, media, account facts or
branding assets were copied.

The reference helper attributes its pipeline inspiration to
[Mharis-code/videoanalyzer](https://github.com/Mharis-code/videoanalyzer).
The [research register](research-provenance.md) retains original canonical
creator-video IDs, attributed claims and caption-based observations; these
are historical source notes, not newly verified performance claims.

OpenAI Whisper, FFmpeg, yt-dlp, Pillow, optional transcript packers and specialist
HyperFrames remain separately installed tools with their own licenses. No
third-party implementation, binaries, model weights or generated assets are
bundled. The optional requirements names do not replace upstream notices.
Diffusion’s fork/pin/upstream provenance is maintained by
[its operation reference](../../diffusion-studio/references/operation.md).

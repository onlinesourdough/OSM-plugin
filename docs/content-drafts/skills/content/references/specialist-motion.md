# Specialist motion

Use upstream [HeyGen HyperFrames](https://github.com/heygen-com/hyperframes)
only for an entire code-animated explainer/motion-graphics video or one bounded
motion overlay asset. Ordinary recorded long-form, shorts, cuts, audio,
captions and general overlays remain Diffusion work.

Start with the available upstream `/hyperframes` router and follow its selected
workflow. If absent, resolve installation through the native harness and
current upstream instructions within installation authority; do not clone a
skill, wrap an installer in a hook or make motion setup obligatory for content.
Keep specialist projects and renders external to the immutable OSM package.

Give each scene one job. Establish where to look before motion starts. Keep
text readable at phone size. Motion explains, reveals or emphasizes; design
the strongest frame before animating. Inspect actual rendered frames and final
export. Use accepted visual direction when available, without an editable
source dependency.

After review, bring back only the final video or bounded overlay the outcome
needs. Register it with real hash, provenance, relationships and its own review
when using a [content graph](graph.md). Preserve external licenses/attribution.
Promote durable motion lessons only at the actual work owner after useful proof.

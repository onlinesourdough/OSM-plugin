# Setup and durable learning

Configure durable business/audience facts, offer or promise, channel policy,
voice, cadence and delivery defaults at the actual work owner. Reuse existing
profile/style sources and resolved caller inputs. Optional neutral
[profile](../assets/templates/profile.md) and [style guide](../assets/templates/style-guide.md)
templates help when no suitable file exists. Copy only what the owner needs
outside the package; do not overwrite owner edits or create a registry.

Keep unknowns unknown. Optional brand defaults are human-readable context, not
a graph schema or a required named channel. Delivery intent and approval-owner
fields do not authorize publication. Design direction is optional and changes
only when its visual-design owner accepts it. A material design gap can route
to the available design method; otherwise complete the authorized defaults.

Inspect the resulting facts, links and applicable owner-local checks. Setup
is complete when the next real outcome and remaining unknowns are clear. It
requires neither a synthetic production nor an editor install/launch. When
video readiness is requested, use Diffusion’s read-only check separately.

After a finished outcome, promote only concrete reusable lessons with evidence
and scope: production lessons to the work owner’s durable learning, proven
voice/reference/performance patterns to its style guide, and analyzed sources
to its reference index. Keep one-off decisions and source media in the actual
production/reference record. Motion principles belong with the owner using
specialist motion. Accepted design remains with its design owner. Never write
learning into an immutable plugin, unrelated owner home, hidden history store
or recovery ledger.

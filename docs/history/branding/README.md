# Historical branding (not current)

`aios-banner.png` is the pixel-bread banner from the AIOS period, before OSM's hub mark. It is kept
unchanged as history. No manifest, document or build uses that banner. The current
mark uses Gustavonline's OSM project artwork as `assets/icon.png`, whose source is
`assets/branding/osm-icon.svg`, without the historical banner. Compatibility markers
named `aios` elsewhere (owner-data filenames, storage keys, backups) are unrelated and stay as they are.

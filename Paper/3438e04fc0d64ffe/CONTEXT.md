# Accepted direction (revision 9 Nov 2026)

Owner feedback accepted: Home = the selected Data & Context home, not global recents/favorites. A quiet overview of the definition's readable sources in definition order, with title search; click → simple reader with breadcrumb, Back, Copy link, Open in Notion. Fewer boxes and disclosures; one gear for Settings. Foundation, setup and Settings structure are preserved. Issues #74 (Home) and #82 (connection), saved links #58, skills #83; no new issue.

Decisions: the projection (osm-home-projection/1) is a derived cache of one definition revision, not an authorable menu. Definition routes, never grants; only OSM's own verified connection authorizes reads, with no fallback to the official plugin's connection. "Edit link…" is the saved-navigation link editor, now a Settings → Saved links sub-view and the manual fallback. Refresh is event-based plus explicit Check again/Try again; no polling. Pasted-link Back restores one verified result row without re-reading; a source that is not completely searched or readable shows its own note, and the global no-match appears only when every source answered complete and empty. Browser sign-in remains planned: OSM's own OAuth registration and backend are unprovisioned.

Status: the revision is implemented in the branch. On 9 November 2026 the designer accepted its rendering in the browser preview with fictional fixture data (render corrections B1–B8 and F1–F3) for a private synthetic candidate. No design blockers remain for that candidate. Not accepted here: the native Codex panel, clipboard and visibility events in the host, live Notion, OAuth, Paper pixel rendering, installation and release. Implementation checks are recorded in the repository's verification record, not in this Paper.

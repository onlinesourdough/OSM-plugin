# Accepted direction (revision 9 Nov 2026)

Owner feedback accepted: Home = the selected Data & Context home, not global recents/favorites. A quiet overview of the definition's readable sources in definition order, with title search; click → simple reader with breadcrumb, Back, Copy link, Open in Notion. One gear for Settings. Issues #74 (Home) and #82 (connection), saved links #58, skills #83; no new issue.

Later owner feedback (supersedes conflicting visuals): Setup's colours, font and whole expression are the approved design source. Home, the source list, the reader, gates and Settings use Setup's palette, host sans family, weights, radius, card/row rhythm and hover/focus/filled-state grammar. Home uses no step numbers; source icons take the number slot. Every listed source ends with the same "Open ‹Source›", including Memory when it has exactly the preview count. Built into OSM is a Setup-style card row that expands like a step, replacing the native triangle and chevron. Page R5 and design.md "Shared foundation" carry the exact values.

Decisions kept: the projection (osm-home-projection/1) is a derived cache of one definition revision, not an authorable menu. Definition routes, never grants; only OSM's own verified connection authorizes reads, with no fallback to the official plugin's connection. Saved links are a Settings sub-view and the manual fallback. Refresh is event-based plus explicit Check again/Try again. The pasted-link Back and incomplete-search rules stand. Browser sign-in remains planned: OSM's own OAuth registration and backend are unprovisioned.

Status: the 9 November revision was implemented and accepted in the browser preview for a private synthetic candidate (B1–B8, F1–F3). The Setup-foundation cohesion correction (R5) is design only; implementation and a fresh render review are pending. Not accepted here: the native Codex panel, clipboard and visibility events in the host, live Notion, OAuth, Paper pixel rendering (native Paper screenshots timed out), installation and release.

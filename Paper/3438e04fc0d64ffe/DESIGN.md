# OSM Home design

The canonical product guide is design.md at the OSM repository root (../../design.md from this source folder). It owns purpose, the definition → overview contract, search and navigation rules, the Shared foundation (Setup tokens, components and states), responsive rules, capability limits, the implementation/issue coverage map and the design acceptance record. This Paper is an illustration of it. Where the boards and the guide differ, the guide wins.

Start with page "R0 · Revision 9 Nov · start here". Pages R1–R4 hold the 9 November 2026 flows and states: a quiet overview of the selected Data & Context home's readable sources with title search, a Notion-like reader with breadcrumb/Back/Copy link/Open in Notion, and one gear for connection, home and saved links. Page R5 "Setup foundation → Home and Settings" shows Setup as the approved visual source carried to Home and Settings. It governs type, weight, radius, card/row grammar and controls wherever R1–R4 differ. Those differences include the two-column wide layout, the 28–32px titles, the borderless search, the conditional Open links and the native disclosure for Built into OSM. The guide's later reader-bar rule (one composition at every width, no root crumb) also supersedes the R2 wide board.

Page "A1 · OSM Data & Context architecture" is the common architecture view for #93: original sources and native histories, the curated Notion home (root and definition, Knowledge, Memory, Skills, optional Content) and the current task session as three wide layers, with Dreaming, the one writer (Manage Data & Context) and task-time capture beside them. Green marks implemented and fixture-tested source, amber source only (Dreaming 1.0.0, not installed), grey not proven. It is generic and holds no owner configuration; an owner-specific view lives in a separate private Paper outside this repository.

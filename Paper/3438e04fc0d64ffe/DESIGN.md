# OSM Home design

The canonical product guide is design.md at the OSM repository root (../../design.md from this source folder). It owns purpose, the definition → overview contract, search and navigation rules, the Shared foundation (Setup tokens, components and states), responsive rules, capability limits, the implementation/issue coverage map and the design acceptance record. This Paper is an illustration of it. Where the boards and the guide differ, the guide wins.

Start with page "R0 · Revision 9 Nov · start here". Pages R1–R4 hold the 9 November 2026 flows and states: a quiet overview of the selected Data & Context home's readable sources with title search, a Notion-like reader with breadcrumb/Back/Copy link/Open in Notion, and one gear for connection, home and saved links. Page R5 "Setup foundation → Home and Settings" shows Setup as the approved visual source carried to Home and Settings. It governs type, weight, radius, card/row grammar and controls wherever R1–R4 differ. Those differences include the two-column wide layout, the 28–32px titles, the borderless search, the conditional Open links and the native disclosure for Built into OSM.

Pages 00–05 and the three Reference pages are preserved earlier versions. Setup S01–S10, connection C03–C09, recovery E05–E10 and onboarding/auth O01–O08 are reused unchanged. Page-first Home P01–P06 and the access disclosure C01–C02 are superseded but kept for comparison.

All text is fictional sample data. Real titles, icons and content come from the source at runtime. Paper uses bundled Inter 400/700 (weight 600 drawn as 700, 500 as 400), fixed artboards and emoji as icon stand-ins; runtime uses the host font, theme and scrolling. A drawing does not prove a live Notion read, an access grant, clipboard or visibility events in the host, or responsive behavior.

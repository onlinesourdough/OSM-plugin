# Select the context home

Use the explicit current choice for the task's owner/client, otherwise that
owner's established pointer and approved guidance. A client setup is not a move
of the consultant's personal home. An unrelated global pointer stays unchanged;
use task/project-scoped routing unless a default-home change is requested.
Prefer a short context entry with direct routes. A home
or Docs index can serve as that entry if it identifies the approved guidance
unambiguously; do not scan all its contents to reconstruct missing instructions.
The guide's title is the owner's choice, not a discovery requirement.
Resolve the exact workspace/account, repository or physical
path before writes. Provider selection is not a search across every account.
An inaccessible chosen guide is a failure of that route, not permission to
create a replacement. If two pointers for the same owner/scope conflict, resolve their ownership
before changing either.

For new context setup without a chosen home, recommend Notion for solo founders,
business leaders and small teams, while checking whether their existing home
already works. Select the home before creating its structure. No configured
home is required for independent work.

For managed-file reading, use AIOS.md, relevant MEMORY.md entries and source
routes. Its supported format is checked before mutation.

The file route means the established AIOS file format, not every folder or
Markdown document. An Obsidian vault or ordinary context repository need not
adopt that format. Git can back up a file home without becoming its agent
runtime. [Continuity Sync](../../osm-maintain-context/references/sync.md) applies
only to an explicitly selected managed file home and its approved Git scope.

Whatever the provider, the write policy and record lifecycle keep the same
semantics: the owner's recorded policy applied by the provider's actual
containment, one current record per topic and scope, and Revised and Review due
only as the [record lifecycle](architecture.md#record-lifecycle) defines them.
Only the physical fields differ.

Carry the resolved provider and operation to the owning skill; do not restart
selection in a loop. A connected home is usable only to the extent observed.
Notion and managed file homes have concrete procedures; other homes use a
bounded adaptation and need their own acceptance evidence. Connector access,
page-based method use, native skill installation and synchronization are separate
claims. Never install a connector, expand sharing or provision a service merely
to make a route appear complete.

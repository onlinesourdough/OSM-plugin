# Optional repository seed

Read only for a requested new template-based repository. A project workspace
does not require Git or this seed. Use existing repository instructions and
history for ongoing work.

The canonical Agentic Project Template is
https://github.com/onlinesourdough/Agentic-project-template.git.
Resolve its live default branch and exact commit, inspect its root instructions
and documented creation interface, then acquire the verified seed in the chosen
new destination. Follow its validation and transfer procedure instead of copying
command flags, generated payload or recovery code into OSM.

For either creation route, use an isolated seed at that fixed revision with no
concurrent writer. Recheck its identity and clean state immediately before
generation; changed source requires fresh verification.

For an in-place seed conversion, verify the exact physical root, Git identity,
source revision and clean state immediately before conversion. Only the verified
template seed may be converted. On failure preserve its reported recovery state.
Re-enter the final root after transfer and inspect generated instructions,
identity, source provenance and expected fresh Git history and remotes.

The template supplies a neutral seed, not a working application or verified
deployment. Populate applicable sources from real facts and implementation;
preserve unresolved decisions until settled. Keep template attribution separate
from the product's licensing decision. Each project type needs only its
applicable authoring, validation and delivery responsibilities.

When the accepted result also needs a substantial engineering foundation, use a
separately selected method such as Agentic Foundation, or report the gap.
The new project owns its files and future maintenance; template provenance is
history, not a runtime dependency or an instruction to refresh existing projects.

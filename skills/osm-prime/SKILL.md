# OSM:prime

Start here when the configured instruction selects Prime or the user asks to
prime a task. Start with the user's request and applicable project instructions.

1. Resolve the scope before opening a source. A task that can clearly be solved
   within an independent project uses its local instructions and sources only.
   General questions without owner context also need no Notion access. Honor
   an explicit project or client context boundary before the personal default.
2. For other tasks, start from the configured context home. Resolve the exact
   selected Notion root through this host's authorized connection. If you have
   no selected root or the connection fails, identify the missing prerequisite
   and continue independent work. Use only the selected home and account.
3. Follow [Manage Data & Context](../osm-manage-data-context/SKILL.md) for
   retrieval. Read the root and its required controls once, then use metadata
   to find only the current knowledge, decisions, sources or methods the task
   needs. Use a scoped Memory query for a past decision and the selected
   history or project source for unfinished work or an activity recap. Verify
   a live fact at its owning source when the result depends on it.
4. Use the relevant result, then proceed with the user's actual request. In
   this session reuse verified context; refresh the affected source only when
   the task, home, scope, freshness or access changes.

Prime does not change context or access, create a new home or write a session
log. Report concrete gaps when they affect the result.

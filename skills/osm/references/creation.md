# Start new work

Reuse the current project or workspace. A project is work with a useful purpose,
context and place for its material; it need not be software or a Git repository.
For new project setup, use [Create Project](../../osm-create-project/SKILL.md)
with the accepted outcome and final location. Native project controls are optional;
OSM adds no second project registration or automatic new task.

Use [Interview](../../osm-interview/SKILL.md) when requested or when material
uncertainty at the start prevents choosing a direction. Reuse accepted answers.
A small self-contained task needs no project setup.

Use [Manage Skills](../../osm-manage-skills/SKILL.md) for reusable methods.
Keep small coding work direct. A substantial software engineering foundation or
repair uses a separately selected method such as Agentic Foundation; if none is
available, report the gap. Continue through the [shared lifecycle](lifecycle.md) proportionately; project
setup, tested application readiness and authorized delivery are separate results.

Preserve existing work, identity and caller instructions. A template, remote or
execution environment is selected only for its actual purpose and authority.

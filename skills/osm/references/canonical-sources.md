# Canonical source route

Use this read-only route only when a current, version, release, source, harness,
or external fact is missing from the accepted input and loaded package. Read the
one relevant source; do not copy or sync it into OSM, Memory, skills,
registries, or a durable owner corpus.

## OSM product facts

Use [local documentation](documentation.md) for the installed version. Read
upstream for a current release, an external fact or a remaining documentation gap.

Read the needed document directly from the canonical OSM product repository.
When it is private, use only an already-authorized native account's ordinary
read path. Never inspect, copy, transport, or ask for credentials; never change
visibility or publish to obtain access. If the read is unavailable, state the
source-access gap rather than make the claim.

need matching active metadata and source/ref or a reviewed release. A harness
fact needs its current official documentation or local help when relevant.

## External facts

The customer's source remains canonical. Read it only with accepted access and
task relevance; re-read it when it changes. If it is unavailable, stale,
inaccessible, or conflicts, report the gap without filling it from memory or
inference. A durable scoped pointer or correction uses
[Manage Data & Context](../../osm-manage-data-context/SKILL.md) and its
[curation procedure](../../osm-manage-data-context/references/curation.md) under
recorded or standing authority; a read-only question never invokes that write
route.
